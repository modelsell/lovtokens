# LovTokens Marketing

This directory is the repository archive for campaign artwork and the scripts
used to reproduce it. Marketing assets live here instead of the application
runtime folders unless the website directly imports them.

## Campaigns

- [`achievement-system-launch`](./achievement-system-launch/): launch posters,
  generated background plates, and the deterministic poster renderer for the
  LovTokens achievement system release.
- [`producthunt-launch`](./producthunt-launch/): Product Hunt submission copy,
  launch-day promotion drafts, the 240 × 240 thumbnail, and three production
  gallery screenshots sized at 1270 × 760.

## Folder convention

Each campaign keeps final and source images under `assets/`, rendering or export
utilities under `scripts/`, and campaign-specific notes in its own `README.md`.
