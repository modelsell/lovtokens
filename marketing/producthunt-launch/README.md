## First comment

Hey Product Hunt 👋

I built LovTokens because token usage across AI coding agents is useful context, but I did not want a dashboard that copied the work behind those numbers.

LovTokens reads known local session locations, extracts aggregate token events, and lets you inspect the complete payload before syncing. It supports Codex, Claude Code, and WorkBuddy; turns activity into private dashboards, opt-in public profiles and leaderboards, achievements, and shareable certificates; and never uploads prompts, replies, code, repository names, file paths, or API keys.

It is free, open source under AGPL-3.0, and works on macOS, Linux, and Windows. You can set it up by sending one sentence to Codex or Claude Code, or use the CLI directly.

I would love your feedback: which usage views help you understand your AI coding habits without turning activity into a productivity score?
